# Lab 3 – Responsive Portfolio Website

## Project Description
This project is a one-page responsive personal portfolio website created using HTML5 and CSS3. It showcases personal information, skills, projects and contact details.

The website uses Flexbox, CSS Grid, media queries and CSS animations to create a simple, modern and responsive design.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- CSS Animations
- Google Fonts (Poppins)

## Features
- Header with navigation links
- Hero section with animated text and profile image
- About Me section
- Skills displayed using CSS Grid
- Project cards with hover effects
- Contact form
- Responsive layout for mobile, tablet and desktop
- Smooth transitions and hover effects
- Back-to-top navigation link

## Responsive Design

The website was tested at the following screen widths:

| Device | Screen Width |
|---|---|
| Mobile | 375px |
| Tablet | 768px |
| Laptop | 1024px |
| Desktop | 1440px |

### CSS Breakpoints
- Mobile: 600px and below
- Tablet: 601px to 900px
- Desktop: Above 900px

## How to Run the Project

1. Download or clone the GitHub repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Resize the browser window to test responsive behaviour.
